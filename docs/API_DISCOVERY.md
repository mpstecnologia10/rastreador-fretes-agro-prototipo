# Aquisição automática de cargas

O motorista escolhe onde ficará vazio. A publicação roda aquisição automática e build REAL; zero é um resultado válido. Fixtures continuam disponíveis no build local com `--demo`. Nenhuma chave, contrato comercial, captura manual ou planilha é pré-requisito de uso.

O catálogo técnico `data/api_registry.json` distingue capacidade (ofertar, listar ou operar), finalidade e direito de leitura/redistribuição. Null significa não comprovado; documentação pública não torna uma API aberta. Fretefy lista registros de integração e publica ofertas, mas requer chave solicitada por e-mail; a [documentação de oferta](https://fretefy.readme.io/reference/post_api-ofertacarga) não demonstra acesso gratuito a uma bolsa pública. A [FreteConnect](https://freteconnect.com.br/documentacao-api) oferece sandbox e operações sobre fretes da própria empresa. Não testamos operações autenticadas. IBGE é contexto, não anúncio.

Semanalmente o discovery lê robots e metadados institucionais, até um sitemap index e um filho, por domínio revisado. Nenhum caminho de API é adivinhado. Docs, feeds, documentos, portais e anúncios candidatos são evidência para revisão, não permissão. Uma indisponibilidade não interrompe os demais domínios. A lista de empresas inclui sementes regionais; o adaptador ANTT lê apenas ETC/CTC nas oito UFs e não publica o CSV bruto. A referência inicial é a [competência outubro de 2026](https://dados.antt.gov.br/dataset/rntrc/resource/6026280b-d547-4702-a0ac-3539ae8ff4a3); validar o esquema e atualizar o recurso quando houver nova competência.

`python3 -m pipeline.discovery --output data/discovery_snapshot.json` gera o levantamento; `python3 -m pipeline.acquisition` executa contratos públicos de leitura já revisados em `data/public_contracts.json`. Cada fonte falha isoladamente. CSV/JSON normalizados passam pelos mesmos controles de prazo, origem, preço/piso, deduplicação e ranking. Documentos, HTML e APIs de esquema desconhecido não são automaticamente interpretados como frete; exigem adaptador específico após comprovar direitos e semântica. Nenhum contrato de carga real aprovado na rodada inicial.

Relatórios de descoberta semanal, empresas mensal e geo quinzenal ficam como artefatos do Actions. Não promovem automaticamente mudanças de autorização. O Pages distribui o último levantamento revisado no repositório e recalcula o catálogo de fretes a cada seis horas. O protótipo não cobra nem pede credenciais ao motorista.
